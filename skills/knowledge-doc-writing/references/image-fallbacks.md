# 图片替代方案

当 Hermes 无法生成或画不好复杂图片时的四种替代策略，按优先级排列。

---

## 层级一：Hermes 自己画（首选）

适用场景：示意图、架构图、流程图、概念图。

| 方案 | Skill | 输出格式 | 适合 |
|------|-------|---------|------|
| 手绘风格图 | `excalidraw` | `.excalidraw` → 在线链接/PNG | 教程配图、流程图、时序图 |
| 架构图 | `architecture-diagram` | SVG/HTML | 系统架构、云基础设施 |
| 信息图 | `baoyu-infographic` | SVG/HTML | 数据可视化、概念对比 |
| 知识漫画 | `baoyu-comic` | SVG/HTML | 科普类文章 |
| HTML 原型 | `claude-design` / `sketch` | HTML | 需要精确布局的复杂标注 |
| ASCII 艺术 | `ascii-art` | 纯文本 | 终端场景 |
| 像素画 | `pixel-art` | PNG | 复古风格插图 |
| p5.js 动画 | `p5js` | HTML/Canvas | 算法可视化、交互演示 |
| Manim 动画 | `manim-video` | MP4 | 数学/算法动态演示 |

---

## 层级二：搜索现成图片

适用场景：真实照片、特定截图、已有资源。

| 方案 | 工具 | 适合 |
|------|------|------|
| 网络搜图 | `web_search` + 浏览器截图 | 概念相关的真实配图 |
| GIF 动图 | `gif-search` (Tenor) | 动态演示 |
| YouTube 截图 | `youtube-content` | 从视频教程截关键帧 |

找到后用 `vision_analyze` 检查图片是否合适，给出链接。

---

## 层级三：图注描述（给人类编辑）

适用场景：需要真实设备截图、照片级插图、复杂箭头标注。

直接输出精确的图片描述，让人类编辑去配图。描述应包含：

- **图片类型**：截图 / 示意图 / 照片 / 图表
- **画面内容**：什么元素、在什么位置
- **标注要求**：箭头指向哪里、文字写什么
- **风格要求**：配色、字体、留白

---

## 层级四：AI 生图

| 方案 | 工具 | 条件 |
|------|------|------|
| ComfyUI | `comfyui` | 需要本地或远程 ComfyUI 服务运行中 |

---

## 操作建议

1. 先判断图的性质：**示意图**（架构/流程/概念）还是**现实图**（照片/截图）？
2. 示意图 → 优先用 excalidraw 或 architecture-diagram 直接生成
3. 现实图 → 先搜，搜不到写图注描述
4. 需要动态演示 → YouTube 截图或 manim-video
